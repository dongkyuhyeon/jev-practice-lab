# 2장. JEV는 어떻게 판단하는가

JEV/System One 인터페이스는 상태(`state`)와 닫힌 질문(`questions`)을 함께 보냅니다. 이 실습은 세 가지 질문 형식을 사용합니다.

## Choice

코드가 정한 후보 중 하나를 고르고 후보별 확률을 반환합니다. 예: 고객 문의를 `billing`, `technical`, `account`, `general` 중 어디로 보낼지 판단합니다. 후보에 필요한 경우 `other`나 사람 확인 경로도 설계해야 합니다.

## Noul

어떤 조건이 참일 확률을 0과 1 사이 값으로 반환합니다. 예: 입력에 민감정보가 포함됐을 가능성입니다. 확률 자체와 “0.70 이상이면 사람 검토” 같은 정책 임계값은 서로 다른 책임입니다.

## Score

순서가 있는 기준 사이의 위치를 점수로 반환합니다. 예: 긴급도를 `일반 → 빠른 대응 → 즉시` 기준으로 평가합니다. 점수를 실제 행동으로 바꾸는 규칙은 일반 코드에 둡니다.

## 판단 이후

```text
모델 응답 → 형식·범위 검증 → 코드 정책 → 사람 확인 또는 후속 처리 → 감사 로그
```

모델의 confidence나 확률은 사실·권한·실행 성공을 보증하지 않습니다. 운영에서는 실제 데이터로 임계값과 오탐·미탐을 평가하고, 위험 행동에 결정적인 권한 검사와 사람 승인을 추가해야 합니다.
