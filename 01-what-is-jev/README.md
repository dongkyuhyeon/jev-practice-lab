# 1장. JEV란 무엇인가

JEV는 상태를 읽고 정해진 질문에 확률적인 판단을 돌려주는 모델입니다. “무엇이든 써 줘”보다 “이 후보 중 무엇인가?”, “이 조건이 참일 가능성은?”, “어느 단계에 가까운가?” 같은 닫힌 질문에 맞습니다.

## 생성과 판단

생성형 LLM은 설명, 계획, 코드, 선택지처럼 새로운 내용을 만듭니다. JEV는 코드나 사람이 미리 정한 선택지와 기준 안에서 판단합니다.

```text
상태 + 닫힌 질문
        ↓
   JEV의 확률 판단
        ↓
응답 검증 + 코드 정책 + 사람 확인
```

예를 들어 고객 문의를 어느 부서로 보낼지는 후보가 명확한 판단 문제입니다. JEV가 후보별 가능성을 반환하면 일반 코드가 임계값을 적용하고, 민감하거나 불확실한 경우 사람에게 넘길 수 있습니다.

## JEV가 하지 않는 일

JEV의 출력은 실행 명령이 아닙니다. 파일 삭제, 메일 전송, 티켓 이동 같은 행동은 별도의 프로그램이 권한과 정책을 확인한 뒤 수행해야 합니다. 높은 확률도 정답이나 안전을 보증하지 않습니다.

따라서 JEV는 생성형 LLM을 대체하는 만능 모델이라기보다, 생성과 실행 사이에서 제한된 판단을 담당하는 구성 요소로 이해하는 편이 좋습니다.
